    CréditosQuem fez cada projeto
    Como instalarAndroid
    1. Toque em Baixar APK no projeto que quiser.
    2. Abra o arquivo baixado pela notificação ou pela pasta Downloads.
    3. Se o Android pedir, ative Permitir desta fonte.
    4. Toque em Instalar. Se o Play Protect avisar, escolha Instalar mesmo assim.
